# 小森病院 ホームページ改善提案書

作成日：2026年6月19日  
対象：小森病院 トップページ（index.html）

---

## エグゼクティブサマリー

現在のホームページは診療情報・連絡先の整備は進んでいるが、**「問い合わせ・転院相談につながる」** という観点では大きな改善余地がある。特に ①ファーストビューの訴求力、②信頼性の視覚化（患者家族の声・スタッフ紹介）、③問い合わせ導線の強化 が最優先課題。

## 2. 課題詳細と改善提案

### 課題①：ファーストビューの訴求力不足

**現状の問題**
- ヒーローバナーはコンテンツエリア内の一要素（縦約100px程度）
- ピンクのグラデーション背景のみ。実写真なし
- キャッチコピー「住み慣れた地域で、最期までその人らしく。」は良文だが視覚的に埋もれている
- ヘッダーのスライドショーは存在するが、ナビゲーションの上にあり「見せ場」になっていない

**改善提案**
```
現状：コンテンツ内の小さなグラデーションバナー
  ↓
改善：ファーストビュー全体を使った大型ヒーローセクション
・実写真（スタッフ×患者様、リハビリシーン、院内廊下）を背景に使用
・Serif フォントで大型キャッチコピーを展開（縦約280px）
・「住み慣れた地域で、最期までその人らしく。」を視覚的な軸に
・スクロール促進のアニメーション追加
```

**期待効果：** ファーストビューでの「ここに任せたい」という情緒的共感の醸成

---

### 課題②：信頼性シグナルの欠如

**現状の問題**
- ご家族・患者様の声が一切掲載されていない
- スタッフ（看護師・理学療法士・介護士・相談員）の顔と名前が見えない
- 「何年の実績」「何名体制」等の数値アピールがない

**改善提案**
```
追加①：「ご家族様の声」セクション（3〜4件）
・入院中・退院後のご家族のコメントを掲載
・写真不要でも有効（イニシャル表示・職業・年代のみで信頼度UP）
・「転院を迷っていましたが…」など共感を呼ぶエピソード形式

追加②：スタッフ紹介セクション
・院長・看護師長・理学療法士・医療相談員の顔写真と一言
・「こんなスタッフが支えます」という安心感の提供

追加③：数値で見る小森病院（スタッツバー）
・療養病床 57床 ／ 24時間医療・看護体制
・開院〇年 ／ スタッフ〇名体制 を視覚化
```

**期待効果：** 問い合わせ前の不安解消、成約率の向上

---

### 課題③：問い合わせ導線の弱さ

**現状の問題**
- 電話番号はサイドバーの1ボックスに収まっており目立たない
- 問い合わせフォームは「入院案内」ページ内に格納（トップから2クリック以上）
- 「まず気軽に相談してほしい」という低ハードルの入口がない

**改善提案**
```
改善①：ヘッダーに電話番号を常時表示（固定ヘッダー化）
・「ご相談・お問い合わせ ☎ 0422-55-8311」を常時ヘッダーに表示
・スマホではタップで発信できるリンクに

改善②：トップページ下部に独立した「お問い合わせ」セクション
・電話番号（大きく）+ FAX番号 + 相談フォームへのリンク
・「まずはお気軽に。施設見学も歓迎です」の低ハードルCTA

改善③：ケアマネ向けFAX導線の強化
・「空床状況はFAXでもご確認いただけます」のテキストと番号を目立たせる
```

**期待効果：** 問い合わせのコンバージョン率向上、電話・FAX両チャネルの活用

---

### 課題④：施設写真の不足

**現状の問題**
- ヘッダーのスライドショー（6枚）以外、コンテンツ内に写真が一切ない
- HTMLコード内に「📷 写真撮影アドバイス」のコメントが多数あるが未実装
- 施設の清潔感・温かさが視覚的に伝わらない

**改善提案**
```
施設ギャラリーセクションの新設
・個室、リハビリ室、デイルーム、食堂、エントランスの5〜6枚
・各写真にキャプション付与（「明るい光が差し込む個室」等）
・「施設を見る・見学を申し込む」リンクへの誘導
```

**期待効果：** 入院前の不安軽減、施設見学申込率の向上

---

### 課題⑤：FAQ・事前情報の欠如

**現状の問題**
- よくある質問がなく、すべて電話対応に依存している
- 入院費用の目安ページへの導線がない
- 転院・入院の具体的な流れがトップから見えない

**改善提案**
```
FAQセクションの新設（例）
Q: 入院の条件はありますか？
A: 長期療養が必要な方（脳梗塞後遺症・認知症・慢性疾患等）を対象としています。
   胃ろう・気管切開など医療処置が必要な方もご相談ください。

Q: 費用はどのくらいかかりますか？
A: 医療保険・介護保険の種別・所得区分により異なります。
   詳しくはお電話でご案内いたします。（0422-55-8312）

Q: 転院の手続きはどのように進めますか？
A: ①お電話・FAXでのご相談 → ②担当者がヒアリング →
   ③入院前診察 → ④転院 の流れです。

Q: 面会はいつでもできますか？
A: 平日・土日・祝日の10:00〜18:00に承っています。
   ご来院前にお電話でご確認ください。

Q: 施設見学はできますか？
A: 平日10:00〜16:00で承っています。
   お気軽にお電話またはFAXでご予約ください。
```

**期待効果：** 電話問い合わせ件数の削減と質の向上、ユーザーの自己解決率UP
